## 📌 Sobre o Projeto

Este repositório contém o código-fonte do portfólio profissional de **João Victor Quaresma de Arruda**. O projeto foi concebido com uma abordagem moderna, minimalista e de alta performance, priorizando código limpo, semântico e sem dependências pesadas de frameworks externos.

### 🌟 Destaques do Design e Arquitetura:
- **Tema Escuro Moderno (*Dark Mode*)**: Paleta de cores cuidadosamente selecionada com tons profundos (`#0a0a0f`) e detalhes em azul suave (`#56b4d8`).
- **Design Responsivo & Fluido**: Layout adaptável a qualquer dispositivo (Mobile, Tablet, Desktop) usando CSS Grid, Flexbox e tipografia fluida com `clamp()`.
- **Efeitos Visuais Sutis**: *Glassmorphism* no cabeçalho fixo, gradientes radiais em segundo plano e animações de entrada suaves via `IntersectionObserver`.
- **Interatividade Nativa**: Formulário de contato inteligente que constrói e aciona mensagens pré-formatadas via protocolo `mailto:`.
- **Desempenho Extremo**: Desenvolvido 100% em **Vanilla Web** (HTML5 + CSS3 + JS nativo), garantindo carregamento instantâneo e pontuação máxima em métricas de performance.

## 💻 Como Executar Localmente

Como o projeto é construído com tecnologias web nativas, não é necessário instalar dependências do Node.js ou gerenciadores de pacotes.

### Pré-requisitos
- Um navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.)
- Opcional: Extensão **Live Server** no VS Code ou equivalente.

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/JoaoQuaresma01/Portifolio-Jo-o-Quaresma.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd Portifolio-Jo-o-Quaresma
   ```

3. **Abra o portfólio:**
   - **Opção 1**: Basta dar um duplo clique no arquivo `index.html`.
   - **Opção 2 (Live Server)**: No VS Code, clique com o botão direito em `index.html` e selecione *Open with Live Server*.
   - **Opção 3 (Terminal / npx)**:
     ```bash
     npx serve .
     ```

## 📦 Como Fazer o Deploy (GitHub Pages)

Para publicar o portfólio gratuitamente via **GitHub Pages**:

1. Acesse o repositório no GitHub: `https://github.com/JoaoQuaresma01/Portifolio-Jo-o-Quaresma`.
2. Vá na aba **Settings** (Configurações).
3. No menu lateral esquerdo, clique em **Pages**.
4. Na seção **Branch**, selecione `main` (ou `master`) e a pasta `/(root)`.
5. Clique em **Save**.
6. Em alguns minutos, seu portfólio estará online no endereço:
   ```
   https://joaoquaresma01.github.io/Portifolio-Joao-Quaresma/
   ```
