## 📌 Sobre o Portfólio

Este repositório contém o código-fonte do portfólio profissional de **João Victor Quaresma de Arruda**.

O projeto foi desenvolvido com foco em performance, design minimalista e código limpo, reunindo de forma clara e visual minha trajetória na área de tecnologia, competências técnicas e principais projetos desenvolvidos.

### 🧭 O que o portfólio apresenta:

- **Apresentação**: Perfil profissional com foco em desenvolvimento Backend e soluções Full Stack.
- **Sobre & Formação**: Detalhes da graduação em Desenvolvimento de Software Multiplataforma (FATEC Votorantim) e certificações complementares.
- **Habilidades Técnicas**: Competências em linguagens, frameworks e bancos de dados (Java, Node.js, TypeScript, React, Angular, Oracle PL/SQL, MongoDB, entre outros).
- **Projetos em Destaque**:
  - **[EstudeMy](https://github.com/JoaoQuaresma01/EstudeMy-FullStack)** — Plataforma gamificada de estudos com trilhas, medalhas e RPG com quiz (*TypeScript, React, Node.js, MongoDB, Tailwind CSS*).
  - **[Vending Machine](https://github.com/JoaoQuaresma01/Vending-Machine-Project)** — Simulação de máquina de vendas orientada a objetos com controle de troco e estoque (*Java, POO*).
  - **[Plataforma Streaming](https://github.com/JoaoQuaresma01/PlataformaStreaming)** — Interface de catálogo sob demanda integrada a API REST de filmes (*React, JavaScript, Webpack, Docker*).
- **Experiência Profissional**: Trajetória profissional detalhada, incluindo atuações na IBM (projetos Fast Shop e MAPFRE Seguros) com foco em sustentação, manutenção e desenvolvimento de sistemas.
- **Formulário de Contato**: Canal interativo para envio rápido de mensagens diretamente para meu e-mail.

## 💻 Como Executar Localmente

Como o projeto é construído com tecnologias web nativas, não é necessário instalar dependências do Node.js ou gerenciadores de pacotes.

### Pré-requisitos
- Um navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.)
- Opcional: Extensão **Live Server** no VS Code ou equivalente.

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/JoaoQuaresma01/Portifolio-Jo-o-Quaresma.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd Portifolio-Jo-o-Quaresma
   ```

3. **Abra o portfólio:**
   - **Opção 1**: Basta dar um duplo clique no arquivo `index.html`.
   - **Opção 2 (Live Server)**: No VS Code, clique com o botão direito em `index.html` e selecione *Open with Live Server*.
   - **Opção 3 (Terminal / npx)**:
     ```bash
     npx serve .
     ```

## 📦 Como Fazer o Deploy (GitHub Pages)

Para publicar o portfólio gratuitamente via **GitHub Pages**:

1. Acesse o repositório no GitHub: `https://github.com/JoaoQuaresma01/Portifolio-Jo-o-Quaresma`.
2. Vá na aba **Settings** (Configurações).
3. No menu lateral esquerdo, clique em **Pages**.
4. Na seção **Branch**, selecione `main` (ou `master`) e a pasta `/(root)`.
5. Clique em **Save**.
6. Em alguns minutos, seu portfólio estará online no endereço:
   ```
   https://joaoquaresma01.github.io/Portifolio-Joao-Quaresma/
   ```
