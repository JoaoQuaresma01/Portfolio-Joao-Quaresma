## 📌 Sobre o Portfólio

Este repositório contém o código-fonte do portfólio profissional de **João Victor Quaresma de Arruda**.

O site foi desenvolvido com foco em performance, acessibilidade e design minimalista, apresentando de maneira visual e objetiva minha trajetória técnica, competências profissionais e projetos práticos.

---

## 🧭 O que você encontra no portfólio

- **Apresentação**: Visão geral do meu perfil profissional focado em desenvolvimento de software Backend e Full Stack.
- **Sobre & Formação**: Minha trajetória acadêmica no curso de Desenvolvimento de Software Multiplataforma (FATEC Votorantim) e certificações em análise de dados e bancos de dados.
- **Habilidades & Tecnologias**: Stack de ferramentas e linguagens utilizadas no dia a dia, incluindo Java, Node.js, TypeScript, React, Angular, Oracle (PL/SQL), MongoDB, MySQL, Git, entre outras.
- **Experiência Profissional**: Atuação técnica em sustentação, manutenção evolutiva/corretiva e desenvolvimento de sistemas em projetos corporativos na IBM (Fast Shop e MAPFRE Seguros).
- **Projetos em Destaque**:
  - **[EstudeMy](https://github.com/JoaoQuaresma01/EstudeMy-FullStack)**: Plataforma gamificada de estudos com sistema de RPG, quiz e trilhas personalizadas (*TypeScript, React, Node.js, MongoDB, Tailwind CSS*).
  - **[Vending Machine](https://github.com/JoaoQuaresma01/Vending-Machine-Project)**: Simulação completa de máquina de vendas orientada a objetos, com controle de estoque, cálculo de troco e módulo de manutenção (*Java, POO*).
  - **[Plataforma Streaming](https://github.com/JoaoQuaresma01/PlataformaStreaming)**: Interface de catálogo sob demanda integrada ao consumo de API REST de filmes (*React, JavaScript, Webpack, Docker*).
- **Canal de Contato**: Formulário interativo para envio rápido de mensagens diretamente para meu e-mail.
